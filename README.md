# \# SandAndSwitch

# 

# SandAndSwitch는 Unity 엔진을 사용하여 개발된 싱글플레이 퍼즐 게임입니다. 플레이어는 모래와 다양한 스위치를 활용하여 퍼즐을 해결하고 레벨을 클리어해야 합니다. 게임에는 컨베이어 벨트, 문, 폭탄, 스파이크 트랩 등 다양한 기믹이 포함되어 있습니다. 현재 프로젝트는 싱글톤 패턴 기반 게임 매니저, 기믹 기반 퍼즐 시스템, 씬 기반 레벨 디자인을 중심으로 구성되어 있습니다.

# 

# \## 기술 스택

# 

# \- Unity 6000.2.10f1

# \- URP 17.2.0

# \- Input System 1.14.2

# \- Cinemachine 3.1.5

# \- Timeline Interaction

# 

# \## 핵심 기술 소개

# 

# \### 1. 게임 매니저와 싱글톤 구조

# 

# \- `Singleton.cs` : Unity 싱글톤 패턴을 구현한 베이스 클래스입니다.

# \- `GameManager\_Hyeonyong.cs` : 게임 상태 관리, 씬 변경, 기믹 클리어 체크를 담당합니다.

# 

# \### 2. 기믹 기반 퍼즐 시스템

# 

# \- `Gimmick.cs` 및 관련 클래스 : 스위치, 문, 컨베이어 벨트, 폭탄, 타이머 등 다양한 퍼즐 요소를 구현합니다.

# \- `CheckClear.cs` : 퍼즐 클리어 조건을 체크합니다.

# \- `InteractiveObject.cs` : 플레이어와의 상호작용을 처리합니다.

# 

# \### 3. 플레이어 제어와 이동

# 

# \- `Player.cs` : 플레이어 이동, 점프, 상호작용을 담당합니다.

# \- `CameraManager.cs` : 카메라 제어를 관리합니다.

# 

# \### 4. 씬과 레벨 디자인

# 

# \- 여러 씬 파일 (Map\_Zone1.unity 등) : 존 기반 레벨 구조를 제공합니다.

# \- `CheckPointData.cs` : 체크포인트 데이터를 관리합니다.

# 

# \### 5. 사운드와 UI

# 

# \- `SoundEffectManager.cs` : 사운드 효과를 관리합니다.

# \- `UIStart.cs` : UI 시작 화면을 처리합니다.

# 

# \### 6. 기타 시스템

# 

# \- `Arrow.cs`, `Rock.cs` 등 : 게임 내 오브젝트 동작을 구현합니다.

# 

# \## 기술 결정 기록

# 

# \### ADR-001. 싱글톤 패턴 채택

# 

# \- 배경 : 게임 매니저와 공통 시스템을 전역에서 접근 가능하게 할 필요가 있었습니다.

# \- 결정 : Singleton<T> 베이스 클래스를 사용하여 싱글톤 패턴을 구현했습니다.

# \- 채택 이유 : Unity에서 전역 접근을 쉽게 하고, 중복 인스턴스 생성을 방지할 수 있었습니다.

# 

# \### ADR-002. 기믹 기반 퍼즐 구조

# 

# \- 배경 : 다양한 퍼즐 요소를 유연하게 추가할 수 있는 구조가 필요했습니다.

# \- 결정 : Gimmick.cs를 베이스로 한 상속 구조를 채택했습니다.

# \- 채택 이유 : 새로운 기믹을 쉽게 확장할 수 있고, 공통 로직을 재사용할 수 있었습니다.

# 

# \### ADR-003. 씬 기반 레벨 디자인

# 

# \- 배경 : 여러 존으로 나누어진 레벨을 관리해야 했습니다.

# \- 결정 : Unity 씬을 존 단위로 분리하고, SceneManager로 전환했습니다.

# \- 채택 이유 : 레벨 로딩과 관리가 용이하며, 에디터에서 편집하기 쉽습니다.

# 

# \## 핵심 흐름

# 

# \- 게임 시작 : GameManager가 씬을 로드하고 플레이어를 초기화합니다.

# \- 퍼즐 해결 : 플레이어가 기믹을 조작하여 퍼즐을 클리어합니다.

# \- 레벨 진행 : 클리어 시 다음 스테이지로 이동합니다.

# \- UI와 사운드 : 상호작용 시 UI와 사운드 효과가 반응합니다.
